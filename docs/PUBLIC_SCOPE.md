# Public scope and content provenance

The public edition includes the reviewed stable application source, native Android
host, original bundled grammar, import prompt/schema, tests and demonstration data.
It publishes the working baseline's functionality while selecting which project
materials are appropriate to distribute.

| Material | Public treatment |
| --- | --- |
| Application and Android integration source | Included |
| Original grammar lessons | Included with editorial limitations and reference notes |
| Demonstration article | Original fictional library-study scenario authored for this edition |
| Test study data | Same original scenario, independent of personal study material |
| Import schema and prompt | Included; sample references adapted |
| Personal articles, screenshots, exports and review history | Excluded |
| Screenshot-derived original sample | Replaced; no source-publication rights were established |
| Signing keys, secrets, archives, APKs and generated output | Excluded |
| Accepted Capacitor 1.0.7 runtime and portable public build | Included after source/dependency review; separate public app ID |
| Historical test delivery packages, private release procedures and internal planning | Excluded |
| Private repository history and personal machine paths | Excluded |

The code is maintained from a canonical development checkout using an explicit
file list. New files are reviewed before inclusion. Public documentation and sample
content have their own maintained source. Synchronization is a deliberate local
operation, not a background service or permission to publish new content online.

The sample's people and study activities are fictional. No personal progress or
real news article is embedded. Imported material belongs to the person importing
it; do not commit personal study exports to this repository.

No open-source license has been selected for this prepared edition. Do not label
it MIT, Apache, or otherwise licensed without an explicit project-owner decision.
