# User guide

## Explore the original demo

Run `npm start`, open the preview URL and select **Try the sample article**.
Review the title and confirm the import. Tap a sentence to see its English
translation, vocabulary and colored sentence roles.

## Add your own study material

Open **How to import from ChatGPT** to copy the format prompt, save the sample or
paste JSON. The same prompt and schema are in `import-kit/`. Prepare study JSON
outside the app, then choose **Import study file** or paste it into the guide.
Check generated translations and sentence annotations before relying on them.

Reimporting the same article asks before updating it. Exact vocabulary identities
share examples and retain review progress; different meanings remain separate.

## Read, listen and review

Use reader controls for full-text or sentence playback. Pause/resume restarts the
current sentence. Vocabulary supports cards, lists, search, filters and example
navigation. Review lets you reveal meanings and mark what still needs practice.
Grammar contains 80 editorially grouped topics; it is not a complete exam syllabus.

## Storage and settings

Browser data stays in this browser profile at this origin. A different port,
browser profile or device has a separate library. Export a backup before clearing
browser data. Restore replaces the current library after confirmation.

Android stores its own library. Native voice settings depend on installed offline
German voices; browser preview cannot reproduce the phone's voice engine settings.
The app does not automatically transfer data between devices.
