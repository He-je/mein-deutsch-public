# Public edition instructions

- This is the reviewed public edition of Mein Deutsch.
- Read `docs/PUBLIC_SCOPE.md` before adding files or examples.
- Shared code changes must also be applied in the canonical private project.
  Its `PUBLICATION_POLICY.md` and export manifest define the maintenance workflow.
- Public-only documents and samples are maintained in the canonical project's
  `publication/public/` directory, then exported here.
- If the canonical checkout is unavailable, describe the required backport; do not
  silently diverge or overwrite another copy.
- Never add personal study files, backups, source screenshots, signing keys,
  credentials, generated APKs, private history or unreviewed experimental files.
- Run relevant tests and report both-copy status. Do not publish, push, or release
  an APK unless the user requests it. Keep docs in English.
